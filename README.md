# זמן עבודה ונוכחות — קבצי שחרור

מאגר זה מכיל קובצי התקנה ועדכון של התוכנה. קוד המקור נשמר במאגר פרטי ואינו נמצא כאן.

להורדה ידנית בחרו מהדורה שפורסמה בלשונית [Releases](https://github.com/Lev-Good/work-clock-releases/releases). טיוטות מהדורה אינן מוצעות לעדכון אוטומטי.

התוכנה בודקת עדכונים אוטומטית כל ארבע שעות. הורדה והתקנה מתבצעות לפי בקשת המשתמש. לפני עדכון נשמר גיבוי בטיחות מקומי; כשל בגיבוי עוצר את הפעולה.

כל התכונות זמינות ללא קוד הפעלה. הנתונים נשמרים מקומית; גיבוי ענן הוא אופציונלי. נעילת הממשק אינה מצפינה את קובצי העבודה. התנאים והזכויות מפורטים ב-LICENSE ובאתר המפתח.
