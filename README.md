# זמן עבודה ונוכחות — קובצי התקנה ועדכון

תוכנת Windows בעברית לניהול זמן עבודה, לקוחות, עבודות ותשלומים. **גרסה נוכחית: 1.2.2**.

[הורדת המתקין](https://github.com/Lev-Good/work-clock-releases/releases/download/v1.2.2/work-clock-setup-1.2.2.exe) · [מה חדש בגרסה](https://github.com/Lev-Good/work-clock-releases/releases/tag/v1.2.2)

מאגר זה מכיל קובצי הפצה ותמונות מסך בלבד. קוד המקור נשמר במאגר פרטי.

התוכנה בודקת עדכונים אוטומטית כל ארבע שעות ומציגה באנר כאשר יש גרסה חדשה. הורדה והתקנה מתבצעות בלחיצת המשתמש; לפני ההתקנה נשמר גיבוי בטיחות מקומי. כשל בגיבוי עוצר את העדכון.

הנתונים נשמרים מקומית. אפשר להגדיר גיבוי לתיקייה קבועה, ל־Google Drive פרטי ול־WebDAV, עם תזמון עצמאי לכל יעד. גיבוי אוטומטי פועל כשהתוכנה פעילה, לרבות במגש המערכת.

כל התכונות זמינות ללא קוד הפעלה. נעילת הממשק אינה מצפינה את קובצי העבודה. המתקין אינו חתום דיגיטלית. התנאים והזכויות מפורטים ב־LICENSE ובאתר המפתח.
